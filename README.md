# Saguaro Sky — Example Luxury Real Estate Site

A fully functional, multi‑page website built for demonstration and portfolio use. It presents a fictional luxury real estate brand (“Saguaro Sky”) with immersive interactions, particle‑based background animation, custom cursor, page transitions, and an integrated contact modal.

**Live preview** (if hosted): `index.html` — open locally in any modern browser.

## 🏠 Features
- Three.js particle field animated background
- GSAP scroll‑triggered reveals and subtle hero parallax
- Responsive bento‑grid service layout
- Case study page with fictional results
- Privacy Policy and Terms of Service pages (example legal content)
- Contact modal that matches the site’s aesthetic
- Mobile‑optimised touch targets and typography
- Desktop‑only custom cursor (hidden on touch devices)

## ⚠️ Important Disclaimer
**Saguaro Sky is not a real company.** This project is entirely fictional and was created as a design & front‑end development exercise. All names, copy, images, and data are for illustrative purposes only. No actual services are offered, and no real client relationship exists.

If you use this code in your own portfolio, please replace the fictional branding with your own content.

## 🛠 Tech Stack
- HTML5 / CSS3 (Tailwind CSS via CDN)
- GSAP 3 + ScrollTrigger
- Three.js r128
- Vanilla JavaScript (strict mode)
- Google Fonts (Outfit)

## 📁 File Structure
```
├── index.html          # Main landing page (navigation, home, services, portfolio, contact)
├── case-study.html     # Detailed fictional case study
├── privacy.html        # Sample privacy policy
├── terms.html          # Sample terms of service
└── README.md
```

## 🚀 Getting Started
Simply open `index.html` in a modern browser. No build step or server required. All external assets (Tailwind, GSAP, Three.js, font) load from CDNs.
